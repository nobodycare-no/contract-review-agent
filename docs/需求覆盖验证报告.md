## 四、实现偏差披露（与规范显式取舍）

| 偏差 | 规范原文 | 实现取值 | 理由 |
|------|---------|---------|------|
| review_rules 增加 created_at | §2.4.9 仅 updated_at | 双时间戳 | 审计完整性 |
| approval_tasks 增加 instance_id/block_reason | 八字段之外 | +2 工程字段 | 跨服务回写定位/blocked 可观测必需 |
| approval_attachments 增加 attachment_id | 未列 | 新增 | (task_id,attachment_id) 去重键 |
| contract_parses 增加 raw_text | 仅 JSON 两列 | MEDIUMTEXT 全文 | 规则重跑免二次下载 |
| 金额归一化 amount_value | 仅片段/位置/状态 | 数值元+raw_text 并存 | 规则引擎数值比较需要 |
| 第九表 agent_runs | §2.4.9 八张表 | 新增运行记录表 | 断点恢复/预算审计/降级溯源 |
| dry-run 与 /metrics 面 | 未要求 | 新增 G2/G4 | 生产级安全阀与可观测面 |
| Web 以同源单页实现 | SDD 曾记 Vue3 构建链 | app/static/index.html 原生JS三视图 | 功能等价、消去 Node 构建面，API/部署面更小 |
| AI 自由裁量层(AI_DISCRETIONARY) | §2.4.6 规则审查字面 | 规则之上叠加语义增量风险层，强制原文证据，失败静默降级 | 补规则库长尾灵活性；规则结果原样保留可回退 |
