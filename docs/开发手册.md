## 全局约束

- 双容器：mysql + app(:18000 唯一入口)；compose 注入 TZ=Asia/Shanghai
- 任何任务终态只能是 done 或 blocked(可重试)——**没有第三种"假成功"**
- 零降级：LLM 失败掀桌是特性；GPU 卡见 deploy/GPU_VLLM_START.md
- 真机用例门控：LC_LIVE=1 才跑（`tests/test_lc_live.py`）

## 风险与回退

| 风险 | 现行对策 |
|------|---------|
| BigModel Key 错误/欠费 | ChatOpenAI 构造或调用即显式报错；健康面/`/app/diag_llm` 可视诊断 |
| 并行工具调用 × 共享 Session | RunContext.serial_lock 串行化（'provisioning' 崩跑实证后修复） |
| flush 失败毒化会话（Doom-loop） | 工具包络异常先 rollback 再回填真实原因给模型自纠 |
| 小模型工具震荡/递归耗尽 | 纠偏轮一次；仍失败 blocked+完整轨迹落库，一键重试 |
| GPU 会话中断 | 重启自愈→blocked（只陈述事实）；重试即真跑 |
| 并发双跑 | 同单互斥 409；批量遇忙跳过计数 |
| GLM 始终思考拉长轮时 | LLM_THINKING=low 仅 Agent 主线（实证 19s→8s/轮）；审查层默认思考+3000 预算 |
| 模型输出发散 | recursion_limit 预算 + 闭环闸门 + 禁止编造条款的提示词自觉 |
