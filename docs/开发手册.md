# 开发手册 — 合同审批审查 Agent（切片计划）

> 范式：迭代增量式 + 垂直切片；每片可演示、测试绿、即提交。

## 切片总览

| 切片 | 内容 | 交付物 |
|------|------|--------|
| T0 | 环境（cra env ✓ / compose up mysql / 建库验证） | 双容器健康 |
| T1 | mock-approval 服务：**6 份审批单画像**（高/中/低风险 docx ×3、md 数据协议×1、**盖章页 PNG 扫描件**×1、缺附件单×1 用于 blocked 演示）+ 四路由 + reset | curl 拉取/下载/回写通 |
| T2 | backend 骨架：8表 ORM + bootstrap(规则11条种子) | 表结构=DDL 校验绿 |

| T4 | 规则引擎三模式 + 命中持久化 | 规则矩阵用例绿 |

| T8 | 文档收尾：需求覆盖验证报告 + 测试评估报告（规则准确率集） | tag v1.0 |

## 全局约束

- 双容器：mock-approval(:8100 内网) / app(:18000 宿主入口)
- MySQL 8 表 = 权威；mock 注册表内存态（reset 可复现）
- Agent 步数 ≤12，兜底回写必达
- LLM 降级：模板意见路径必须始终可用
- 提交规范同项目 A；每切片绿测后 commit

## TDD 强制范围

rule_engine 三模式匹配矩阵 / fetcher 去重逻辑 / parser 字段提取 / agent_loop 工具调度（mock LLM）。

## 风险与回退

| 风险 | 回退 |
|------|------|
| Qwen3 function-calling 不稳定 | 兜底强制回写已保收敛；另提供「纯代码直调七工具」的确定性模式开关 |
| tesseract 中文识别差 | blocked 演示 + 文档标注限制 |
| OCR 镜像构建慢 | 预拉基础镜像 / 使用国内源 |
