## 全局约束

- 三容器：mysql / mock-approval(:8100 内网) / app(:18000 宿主唯一入口)
- compose 项目名 `contract-review-agent` 显式声明，绝不触碰项目 A 的 kbnet 体系与其文件
- MySQL 八表=规范权威，agent_runs=登记过的工程超集；mock 注册表内存态（reset 复现）
- RunController 三维预算兜底必达：任何任务终态只能是 done 或 blocked(可重试)
- GPU（AutoDL Qwen3-8B）仅在 T6b 与最终演示开机；其余切片离线完成（轨迹回放保 CI）

## TDD 强制范围

rule_engine 三模式匹配矩阵 / fetcher 去重 / parser 提取与归一化 / 工具包络与错误分类 / RunController 全分支（正常·预算触顶·熔断·断点恢复·dry-run·幂等守卫）/ schema-alignment。

## 风险与回退

| 风险 | 回退 |
|------|------|
| vLLM 未开 tool-call-parser 参数 | ADR-B7 能力探测自动降级 JSON 协议通道；两通道共用执行器 |
| GPU 会话中断/网络抖动 | 断点恢复 resume + 熔断器切确定性通道，任务不丢 |
| Qwen3 输出发散 | 步数/token/墙钟三维预算优雅终结；另有纯代码直调确定性模式开关 |
| tesseract 中文识别差 | inst-005 实测校准阈值；仍失败走 blocked 演示 + 文档标注限制 |
| OCR 镜像构建慢 | 预拉基础镜像 / 国内源 |
| 云端安全 | 安全组仅放行 22+18000；MySQL/mock 无宿主口；Admin Token 管理面 |
