## 全局约束

- 三容器：mysql / mock-approval(:8100 内网) / app(:18000 宿主唯一入口)
- compose 项目名 `contract-review-agent` 显式声明，绝不触碰项目 A 的 kbnet 体系与其文件
- MySQL 8 表 = 权威；mock 注册表内存态（reset 可复现）
- Agent 步数 ≤12，兜底回写必达；LLM 降级模板意见路径必须始终可用
- GPU（AutoDL Qwen3-8B）仅在 T6 集成联调与最终演示时开机；其余切片离线完成

## TDD 强制范围

rule_engine 三模式匹配矩阵 / fetcher 去重逻辑 / parser 字段提取与归一化 / agent_loop 工具调度（mock LLM）/ schema-alignment。

## 风险与回退

| 风险 | 回退 |
|------|------|
| vLLM 未开 tool-call-parser 参数 | ADR-B7 能力探测自动降级 JSON 协议通道；两通道共用工具执行器 |
| Qwen3 输出发散/死循环 | 步数上限 + 强制兜底回写已保收敛；另有「纯代码直调七工具」确定性模式开关 |
| tesseract 中文识别差 | inst-005 扫描件实测校准阈值；仍失败走 blocked 演示 + 文档标注限制 |
| OCR 镜像构建慢 | 预拉基础镜像 / 使用国内源 |
| 云端服务器安全 | 安全组仅放行 22+18000；MySQL/mock 不暴露宿主端口；管理面 Admin Token |
