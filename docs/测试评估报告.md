## 三、V2 开发期真实缺陷与修复实录

| # | 缺陷 | 根因 | 修复 |
|---|------|------|------|
| 1 | AgentExecutor 在 LangChain 1.x ImportError | 引擎 API 迁移 | 切 langchain.agents.create_agent |
| 2 | 重试端点只复位不跑引擎 → parsing 悬置 | legacy 设计残留 | retry=复位+同步真跑引擎 |
| 3 | legacy 静默 llm_down 假成功 | 降级哲学 | 防降级绊线（LC_LIVE 用例）当场击杀 |
| 4 | get_contract_approval 引用已删除 mock | 物理删除漏网 | 接本地审批域（模型自主决策首曝） |
| 5 | 工具实参被空 schema 吞掉 | args_schema 无字段 | TOOLS_SCHEMA 动态强类型 |
| 6 | save 静默模板兜底意见 | 确定性文案兜底 | comment_text 缺失即拒绝 |
| 7 | risk 中文/英文两套值域 → 前端不显示 | 模型直传中文枚举 | 工具边界归一 |
| 8 | dedup 短路不闭环状态 → 成功被误标 blocked | 幂等守卫缺迁移 | 短路路径补 transition(done) |
| 9 | 批量工人吞异常 → parsing 孤儿 + UI 锁死 | 吞异常连吞状态 | 显式 blocked + 自愈 + batch 账本 |
| 10 | 服务端耗时显示 0.0s | 字段算了没回传（测试桩掩盖） | 返回体补 elapsed_ms + 非桩测试 |
| 11 | GraphRecursionError 真机掀桌 | 小模型工具震荡 | 纠偏轮一次（真机 60.3s 救回实录） |
| 12 | EXC 轨迹匿名 | 只记两字母 | EXC:<原因前120字> 入轨迹与闸门报错 |
| 13 | 失败路径二次崩溃（会话 prepared 态） | 损坏事务直接 block_task | 失败路径先 rollback |
| 14 | 六份基线文档被 shell 双重编码成乱码 | pwsh 会话 GBK 误读 | git 恢复原件+编辑工具重写 |
