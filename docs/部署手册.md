# 部署手册 — 合同审批审查 Agent（云端生产）

> 目标环境：**新购独立云服务器**（与项目 A 物理隔离；项目 A 的任何文件/容器/配置均不在本手册操作范围内）。
> GPU 不上云：LLM 推理复用 AutoDL Qwen3-8B 公网映射端点，GPU 关机时系统自动降级纯规则模板模式，服务不中断。

## 1. 服务器选型与初始化

| 项 | 建议值 |
|----|--------|
| 厂商 | 腾讯云 / 阿里云均可（按价格与地域自选） |
| 规格 | 2核4G 起（MySQL+双 FastAPI 容器余量充足）；系统盘 40G+ |
| 系统 | Ubuntu 22.04 LTS |
| 安全组 | 放行 `22/tcp`（限本人 IP 更佳）与 `18000/tcp`；**其余全部拒绝** |
| 带宽 | 5M 固定带宽或按流量（附件为 KB 级 docx/PNG，压力小） |

```bash
# 系统更新 + 基础工具
sudo apt update && sudo apt -y upgrade
sudo apt -y install git curl ufw
sudo ufw allow 22/tcp && sudo ufw allow 18000/tcp && sudo ufw enable
```

## 2. 安装 Docker（国内源）

```bash
curl -fsSL https://get.docker.com | sudo sh
sudo systemctl enable --now docker
sudo usermod -aG docker $USER   # 重新登录生效
docker compose version          # v2 插件随装即有
```

## 3. 拉取代码与配置

```bash
sudo mkdir -p /opt && cd /opt
sudo git clone https://github.com/nobodycare-no/contract-review-agent.git
cd contract-review-agent

cp deploy/.env.example .env
vim .env    # 必改三项：
#   ADMIN_TOKEN=<强随机串>
#   DB_ROOT_PASSWORD=<强密码> 与 deploy/docker-compose.yml 中 mysqladmin 探针一致
#   LLM_BASE_URL=https://<AutoDL实例公网映射域名>/v1   （GPU 开机后填）
```

## 4. 生产启动（override 叠加）

```bash
cd /opt/contract-review-agent/deploy
docker compose -f docker-compose.yml -f docker-compose.prod.yml up -d --build
```

prod override 行为（deploy/docker-compose.prod.yml）：
- 全服务 `restart: unless-stopped`
- 移除 mock-approval 的 `127.0.0.1:18100` 回环调试口
- app 保持 `18000:8000` 对外
- MySQL **无宿主端口映射**（仅 cranet 内网）
- attachments 使用命名卷 `attachment_data` 持久化

## 5. 验收探针

```bash
# 容器内跑 AC-1~7 全量探针（28 项风格同项目 A）
docker compose -f docker-compose.yml -f docker-compose.prod.yml \
  exec app python -m app.acceptance.probe --base-url http://localhost:8000
```

浏览器验收：`http://<服务器公网IP>:18000/` 打开简易工作台 → 触发一次闭环演示 → 任务详情页可见解析字段/命中证据/回写状态。

## 6. GPU 协同（AutoDL）

1. AutoDL 开机 → 复制公网映射 URL（`:8443` 那台）→ 更新 `.env` 的 `LLM_BASE_URL`
2. `docker compose ... restart app` 使配置生效
3. `GET /health` 返回体中 `llm: reachable` 即接入成功
4. GPU 关机无需动云端：agent_loop 能力探测失败自动走模板模式（ADR-B5/B7），task_logs 有 warn 记录

## 7. 数据备份与运维

```bash
# 每日备份 MySQL（crontab 示例：凌晨3点）
0 3 * * * cd /opt/contract-review-agent/deploy && \
  docker compose exec mysql sh -c 'mysqldump -uroot -p"$MYSQL_ROOT_PASSWORD" contract_review' \
  > /opt/backups/cra_$(date +\%F).sql

# 日志查看
docker compose logs -f app --tail=200
```

升级流程：`git pull` → `docker compose ... up -d --build` → 重跑探针。

## 8. 与项目 A 的隔离声明

本项目使用独立仓库、独立 compose 项目名（`contract-review-agent`）、独立网络（cranet）与数据卷（mysql_data/attachment_data）；宿主端口 18000/18100 与 A 的 8081/13306/19530 无交集。本手册所有命令均在 B 自身目录内执行。
